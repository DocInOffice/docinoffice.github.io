DocInOffice

Проект DocInOffice представляет программы расширений (Add-In) для Microsoft Office.

FB2 Add-In

Программа позволяет создавать и редактировать электронные книги формата FB2 (FictionBook 2) непосредственно в редакторе Microsoft Word.

FB2 Word Viewer

Программа позволяет открывать и читать электронные книги формата FB2 (FictionBook 2) прямо в Microsoft Word, а также легко сохранять их в других форматах.

Скачать

CSV 4180

Программа предназначена для работы с файлами данных формата CSV (Comma-Separated Values) в электронных таблицах Microsoft Excel. Загрузка и сохранение данных выполняются в строгом соответствии со стандартом RFC 4180.
